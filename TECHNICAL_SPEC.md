# Техническое задание (ТЗ)

## English AI Tutor — ИИ-репетитор английского языка

**Версия:** 1.0  
**Дата:** 2026-08-18  
**Статус:** Черновик

---

## 1. Общее описание

### 1.1. Цель проекта
Создать полноценного ИИ-репетитора английского языка, который **полностью заменяет живого преподавателя**. Приложение должно предоставлять структурированную программу обучения по трём ключевым направлениям: **грамматика**, **слушание (аудирование)** и **разговорная речь (speaking)**, с автоматическим определением уровня языка через тестирование.

### 1.2. Целевая аудитория
- Взрослые и подростки (14+), изучающие английский язык
- Уровни: от A1 (Beginner) до C2 (Proficiency) по шкале CEFR
- Пользователи, которые хотят заниматься самостоятельно без живого преподавателя

### 1.3. Платформа
- **Telegram Web App** (основной интерфейс) — доступен через Telegram-бота
- **Веб-версия** (браузер) — расширенный интерфейс для ПК
- **Мобильная адаптация** — оптимизация под смартфоны

### 1.4. Ключевые принципы
1. **Полная замена преподавателя** — приложение должно вести ученика от определения уровня до достижения цели
2. **Структурированная программа** — не случайные уроки, а последовательная учебная программа
3. **Адаптивность** — программа подстраивается под прогресс и слабые места ученика
4. **Современный UI/UX** — красивый, интуитивный, современный дизайн
5. **Геймификация** — мотивация через XP, уровни, награды, серии (streaks)

## 2. Функциональные требования

### 2.1. Определение уровня языка (Placement Test)

#### 2.1.1. Адаптивный тест (Adaptive Testing)
- **Алгоритм:** адаптивный тест, который подстраивает сложность вопросов под ответы пользователя
  - Начинается со среднего уровня (B1)
  - При правильном ответе — следующий вопрос сложнее
  - При неправильном — проще
  - Тест завершается после 15–20 вопросов или при стабилизации уровня
- **Формат вопросов:**
  - Грамматика (выбор правильной формы, заполнение пропусков)
  - Лексика (синонимы, антонимы, словообразование)
  - Чтение (короткие тексты с вопросами на понимание)
  - Аудирование (прослушивание фразы и выбор ответа)
- **Результат:** точный CEFR-уровень (A1–C2) с детальным отчётом по навыкам

#### 2.1.2. Детальный отчёт по навыкам
После теста пользователь получает:
- Общий CEFR-уровень
- Оценку по каждому навыку: грамматика, лексика, аудирование, чтение
- Рекомендации по фокусу обучения

#### 2.1.3. Повторное тестирование
- Возможность пересдать тест через 30 дней
- Сравнение результатов (прогресс)

### 2.2. Программа обучения (Learning Path)

#### 2.2.1. Структура программы
Программа построена по принципу **уровней → модулей → уроков**:

```
Уровень (A1, A2, B1, B2, C1, C2)
  └── Модуль 1 (тема: "Introductions")
        ├── Урок 1: Грамматика (Present Simple)
        ├── Урок 2: Лексика (greetings, introductions)
        ├── Урок 3: Аудирование (прослушивание диалога)
        ├── Урок 4: Разговор (ролевая игра)
        └── Тест модуля
  └── Модуль 2 (тема: "Daily Routine")
        └── ...
```

#### 2.2.2. Направления обучения

##### 📘 Грамматика
- **Темы по уровням CEFR:**
  - A1: Present Simple, Present Continuous, артикли, множественное число, личные местоимения
  - A2: Past Simple, Future Simple, модальные глаголы (can, must), предлоги времени
  - B1: Present Perfect, Past Continuous, условные предложения (0, 1 тип), пассивный залог
  - B2: Conditionals (2, 3 тип), Reported Speech, Gerund/Infinitive, Relative Clauses
  - C1: Inversion, Mixed Conditionals, Subjunctive, Advanced Passive
  - C2: All advanced structures, stylistic variations, idiomatic grammar
- **Формат уроков:**
  - Теория (краткое объяснение с примерами)
  - Интерактивные упражнения (заполнение пропусков, выбор, перестановка слов)
  - Практика в контексте (мини-тексты с использованием правила)
  - Проверка понимания (тест в конце урока)

##### 🎧 Аудирование (Listening)
- **Форматы:**
  - Аудио-диалоги (повседневные ситуации)
  - Подкасты (адаптированные по уровню)
  - Новости (упрощённые)
  - Песни с разбором текста
- **Упражнения:**
  - Прослушать и ответить на вопросы
  - Заполнить пропуски в транскрипте
  - Определить основную идею
  - Различить детали (числа, имена, время)
- **Скорость речи:** регулируется по уровню (медленная → естественная)

##### 🗣️ Разговорная речь (Speaking)
- **Форматы:**
  - Голосовой диалог с ИИ (реальное время)
  - Ролевые игры (в ресторане, в аэропорту, собеседование)
  - Описание картинок
  - Ответы на вопросы (IELTS-style)
  - Монологи на заданную тему
- **Обратная связь:**
  - Транскрипция речи (STT)
  - Исправление грамматических ошибок
  - Оценка произношения (фонетический анализ)
  - Рекомендации по улучшению

##### 📖 Чтение (Reading)
- **Форматы:**
  - Адаптированные тексты по уровню
  - Статьи, рассказы, новости
  - Диалоги и письма
- **Упражнения:**
  - Вопросы на понимание
  - Заполнение пропусков
  - Определение значения слов по контексту

##### ✍️ Письмо (Writing)
- **Форматы:**
  - Эссе, письма, сообщения
  - Описания, рассказы
- **Обратная связь:**
  - Проверка грамматики и орфографии
  - Оценка структуры и связности
  - Рекомендации по стилю

#### 2.2.3. Система прогресса
- **Прогресс по модулям:** процент завершения каждого модуля
- **Прогресс по навыкам:** отдельный прогресс для грамматики, аудирования, разговора, чтения, письма
- **Общий прогресс уровня:** сколько процентов уровня пройдено
- **XP и уровни:** начисление XP за выполнение заданий
- **Streak (серия):** ежедневная серия занятий

#### 2.2.4. Принцип i+1 (Comprehensible Input)
- Контент каждого урока должен быть **чуть сложнее** текущего уровня ученика (гипотеза Крашена)
- Алгоритм подбора сложности: на основе уровня + прогресса + типичных ошибок
- Не перегружать: максимум 10–15% нового материала за урок
- Адаптация скорости речи и сложности текстов под уровень
- Для начинающих (A1): "тихий период" — сначала слушание и понимание, потом говорение

#### 2.2.5. Task-Based Learning (обучение через задачи)
- Каждый модуль содержит 1–2 реальные задачи (TBLT)
- Примеры задач:
  - A1: "Закажи кофе в кафе", "Представься на собеседовании"
  - B1: "Запишись к врачу", "Забронируй отель"
  - C1: "Проведи презентацию", "Участвуй в дебатах"
- **Оценка по результату задачи** (достиг ли цели), а не только по грамматике
- Три типа задач: информационный разрыв, разрыв в рассуждениях, разрыв во мнениях

#### 2.2.6. CLIL (контентные модули)
- Модули, где язык изучается через интересный контент:
  - "Наука на английском" (B1+)
  - "Бизнес на английском" (B2+)
  - "История и культура" (A2+)
  - "Технологии и инновации" (B1+)
- Язык усваивается как побочный продукт изучения содержания

#### 2.2.7. Иммерсивный режим
- Опция: полностью английский интерфейс
- Ежедневные "погружения": 10–15 минут контента на английском
- Аутентичные материалы (статьи, новости, видео), адаптированные по уровню

#### 2.2.8. Формат заданий IELTS/TOEFL
- Для уровней B1+ добавить задания в формате экзаменов:
  - Эссе (IELTS Task 2)
  - Монологи (IELTS Speaking Part 2)
  - Описания картинок
  - Академическое чтение
- Оценка по критериям: структура, связность, лексика, грамматика

### 2.3. Интеллектуальные функции ИИ

#### 2.3.1. Адаптация под ученика
- **Анализ ошибок:** система отслеживает типичные ошибки ученика
- **Персонализация:** уроки подстраиваются под слабые места
- **Повторение:** система интервального повторения (SRS) для слов и правил

#### 2.3.2. Контекстный диалог
- ИИ помнит контекст разговора
- Поддерживает естественную беседу
- Корректирует ошибки в реальном времени

#### 2.3.3. Генерация контента
- Уроки генерируются под уровень и интересы ученика
- Подкасты на любую тему
- Диалоги для ролевых игр

#### 2.3.4. Affective Filter (безопасная среда)
- ИИ всегда позитивно реагирует на попытки ученика
- Хвалит за старание, а не только за правильность
- Ошибки подаются как "возможность для роста", а не как провал
- Для начинающих: "тихий период" (сначала слушание, потом говорение)

#### 2.3.5. Testing Effect (активное припоминание)
- Больше заданий на recall (вспомнить) вместо recognition (узнать)
- Примеры:
  - "Напиши перевод слова" (вместо "выбери перевод")
  - "Заполни пропуск" (вместо "выбери из вариантов")
  - "Перескажи текст" (вместо "ответь на вопросы")
- Тесты используются как инструмент обучения, а не только оценки

### 2.4. Геймификация

| Элемент | Описание |
|---------|----------|
| **XP** | Очки опыта за выполнение заданий |
| **Уровни** | Ранги (Bronze → Silver → Gold → Platinum → Diamond) |
| **Streak** | Серия дней подряд занятий |
| **Награды** | Бейджи за достижения (первый урок, 7-дневная серия и т.д.) |
| **Лидерборд** | Рейтинг среди друзей/всех пользователей |
| **Ежедневные цели** | Задания на день (например, "пройди 1 урок грамматики") |
| **Daily Practice** | Короткие ежедневные уроки (5–10 минут) с бонусным XP |

### 2.5. Словарь и интервальное повторение (SRS)

- **Личный словарь:** пользователь добавляет слова, которые хочет запомнить
- **Алгоритм SRS:** интервальное повторение (аналог Anki)
- **Карточки:** слово + перевод + пример + аудио произношение
- **Ежедневные напоминания:** бот напоминает о словах для повторения
- **SRS для грамматики и фраз:** не только слова, но и грамматические конструкции, идиомы, фразовые глаголы, целые фразы для разговорной практики

### 2.6. Статистика и аналитика

- **Ежедневная статистика:** сколько времени занимался, сколько слов выучил
- **Недельный отчёт:** прогресс за неделю
- **Месячный отчёт:** сравнение с прошлым месяцем
- **Графики:** визуализация прогресса по навыкам

### 4.3. База данных

#### Таблица `users`
```sql
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    level TEXT DEFAULT 'A2',           -- CEFR уровень
    xp INTEGER DEFAULT 0,              -- очки опыта
    streak INTEGER DEFAULT 0,          -- серия дней
    last_active DATE,                  -- последняя активность
    rank TEXT DEFAULT 'Bronze',        -- ранг
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### Таблица `lessons`
```sql
CREATE TABLE lessons (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    module_id INTEGER,                 -- модуль
    lesson_type TEXT,                  -- grammar/listening/speaking/reading/writing
    title TEXT,
    content TEXT,                      -- JSON с контентом урока
    completed BOOLEAN DEFAULT 0,
    score INTEGER,                     -- оценка за урок
    completed_at DATETIME
);
```

#### Таблица `modules`
```sql
CREATE TABLE modules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    level TEXT,                        -- A1-C2
    title TEXT,
    description TEXT,
    order_index INTEGER
);
```

#### Таблица `words` (SRS)
```sql
CREATE TABLE words (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    word TEXT,
    translation TEXT,
    example TEXT,
    level TEXT,
    next_review DATE,
    interval INTEGER DEFAULT 0,
    ease_factor REAL DEFAULT 2.5,
    repetitions INTEGER DEFAULT 0
);
```

#### Таблица `errors`
```sql
CREATE TABLE errors (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    original TEXT,
    corrected TEXT,
    context TEXT,
    error_type TEXT,                   -- grammar/vocabulary/pronunciation

```

## 6. Критерии приёмки

### 6.1. Функциональные критерии
- [ ] Тест уровня определяет CEFR-уровень с точностью ≥ 80%
- [ ] Программа обучения содержит минимум 6 модулей на каждый уровень (A1–C2)

- [ ] Система XP и streak работает корректно
- [ ] Словарь с SRS работает корректно

### 6.2. UI/UX критерии
- [ ] Интерфейс адаптирован под мобильные устройства
- [ ] Все анимации плавные (60 FPS)
- [ ] Время загрузки страницы < 3 секунды
- [ ] Все элементы доступны с клавиатуры
- [ ] Поддержка тёмной и светлой темы

### 6.3. Технические критерии
- [ ] API отвечает за < 500 мс (без учёта LLM)
- [ ] База данных не теряет данные
- [ ] Обработка ошибок LLM (fallback на статические данные)
- [ ] Безопасность: нет утечки API-ключей
